Simple Workspaces test checklist

This Firefox window uses a separate test profile, so your normal tabs are untouched. The add-on is already installed and reloads by itself every time the code changes. Your answers here are saved in this profile.

Before you start

  1. Click the Simple Workspaces toolbar button and create two workspaces, named W1 and W2.
  2. In W1, open a few sites using the links below. Then select 3 tabs, right-click, and choose Add Tabs to New Group. Name the group A.
  3. Select 2 other tabs the same way and make group B.
  4. Switch to W2, open 2 tabs and make group C.

Sample sites: example.com, mozilla.org, MDN, Wikipedia, the repo.
